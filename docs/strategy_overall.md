# 赛马娘育成 总体策略（自动化程序用）

> 来源：GameKee《赛马娘入坑指南》（`https://www.gamekee.com/smn/153686.html`，NGA「恐惧黎明Ou」授权转载）。
> 该文是**总体概念**层面的保姆级指南，覆盖了育成的通用机制。本文档把它整理成**可直接指导自动化决策的通用策略框架**。
>
> ⚠ **重要**：不同剧本（URA / 青春杯 / 巅峰杯 / 凯旋门）的**具体回合策略不同**。本文件只描述**通用/总体**的部分；各剧本的专用策略分别在
> `module/umamusume/scenario/{ura,aoharuhai,kaisen}_scenario.py` 以及 `script/cultivate_task/` 中实现。
> 原文发布于日服 2022 版本（含「巅峰杯」）。本程序（国服续更版）第三剧本为**凯旋杯/凯旋门**，其具体机制仍在完善（见 `KaisenConfig`）。

---

## 0. 育成流程一句话概述

赛马娘的核心玩法是**回合制「育成」**：用约 3 年（约 60+ 回合）把一只马娘培养到足以通过**生涯目标**，同时把**五维属性**和**技能**练上去。

每一回合只能做一件事，可选动作对应程序的 `TurnOperationType`：

| 动作 | 说明 | 程序枚举 |
|------|------|----------|
| 训练 | 选择一种训练项（速/耐/力/根/智），拿属性+技能点 | `TRAINING` |
| 比赛 | 参加生涯目标赛或额外比赛，拿属性/技能点/技能提示 | `RACE` |
| 休息 | 回大量体力（会消耗回合，收益为零） | `REST` |
| 保健室 | 回体力 + 解除异常状态（可用时优于纯休息） | `MEDIC` |
| 外出 | 散步/祈福/唱K，主要**提升心情**，少量回体力 | `TRIP` |

育成成功与否 = 是否在当前回合前达成所有**生涯目标**（特定比赛的名次，或某时间点的粉丝量）。未达成则失败，本局结束。

## 1. 五维属性（`TrainingType` 顺序：速/耐/力/根/智）

| 属性 | 含义 | 重要度 |
|------|------|--------|
| 速度 Speed | 全部马娘的基本盘 | 越高越好；唯一例外是大赛「妨害特化」马 |
| 耐力 Stamina | 就是「HP」 | 距离越长需求越高；不够会**失速散步/后程崩盘** |
| 力量 Power | 位置争夺、冲出马群、加速度 | 速耐达标后越高越好 |
| 根性 Will/Guts | 位置争夺、终盘冲刺、耐力不足时的兜底速度 | 速耐达标后越高越好 |
| 智力 Intelligence | 技能发动率、降低焦躁失效、巡航/终盘速度、位置意识 | **持续有效**；智力训练回体力、给大量技能点 |

**通用培养优先级（按比赛距离）：**

- 短距离：速度 + 力量（或速度 + 智力），耐力无硬性要求
- 英里：速度 + 智力 / 力量（可借耐力因子或回体技能）
- 中距离：速度 + 力量 / 耐力
- 长距离：速度 + 耐力（耐力是硬门槛，务必配回耐技能）

> 对应「配卡思路」：支援卡**不要五种平均分**，要**集中 2~3 个属性**。常用组合：
> `速力`（高速高力、借力训练顺便补耐）、`速耐`（长距离）、`速智`（用智力训练的回复效果拉高上限）。
> 配卡应与 `expect_attribute`（培育目标属性）匹配——README 的「注意事项 3」也强调：带了 3智3速 就别设很高的耐/力目标。

## 2. 每回合通用决策逻辑（对应 `ai.py` 的 `get_operation`）

程序已经在 `module/umamusume/script/cultivate_task/ai.py` 里做了通用近似，此处给出**背后的策略依据**（即「总体概念」）。每回合按以下顺序判定：

1. **出道战优先**：尚未赢下出道赛前，一律先跑出道赛。
2. **硬性比赛回合**：命中生涯既定赛程 / `extra_race` 的回合，直接 `RACE`（目标名次赛不可避开）。
3. **回体力判定**：
   - 体力过低（≈ ≤48）→ `REST`（或可用时 `MEDIC` 更优）。
   - 体力中等偏低 + **心情差**（绝好调以外）→ 先用 `TRIP` 提心情，同时少量回体力。
   - 合宿前（如第 36 / 60 回合）体力仍不足 → 提前休息，保证满体力进场。
4. **训练选择打分**（5 种训练项择优得分最高者）：
   ```
   某训练项得分 = 属性收益分 × 属性权重
               + 支援卡分   × 支援卡权重
               + 训练等级分 × 等级权重
               + 事件分(支援卡红点, URA 专用)
   ```
   - **属性收益分**：看这一项「距离当前属性缺口」的边际价值——越缺的属性训练越值钱；缺口已满则按「总增值」计（此时额外属性不再倍增权重）。
   - **支援卡分**：该项上有几张、类型是否匹配、羁绊是否满 4 格（触发**友情训练/彩圈**）。
   - **训练等级分**：训练等级越高，该项增值越大（`get_training_level_score`）。
   - **阶段加权**（近似）：前期抢等级/羁绊 → 支援卡权重大；中后期 → 属性权重大；合宿期 → 属性权重拉到最大。
5. **心情管理**（贯穿全程）：心情影响训练收益（±10%~±20%）与比赛属性（±2%~±4%）。策略上**尽量维持绝好调**，心情下降时优先用外出/事件找回。

> 注意：`ai.py` 中的日期边界（36/40/48/60/64）与权重是**通用近似**，并不区分剧本。真正的剧本差异（青春杯的魂爆、巅峰杯的商店、凯旋杯的远征等）需要在各剧本策略层覆盖，而不是塞进通用函数。

## 3. 心情与体力的量化（写成规则可直用）

**心情 5 档**（越高越好）：

| 档 | 训练效果 | 比赛属性 |
|----|----------|----------|
| 绝好调 | +20% | +4% |
| 好调 | +10% | +2% |
| 普通 | 0 | 0 |
| 不调 | -10% | -2% |
| 绝不调 | -20% | -4% |

- 提升：外出（散步/祈福/唱K）、部分事件、比赛获胜后事件。
- 下降：负面事件、**连续跑 3 场比赛**、训练失败。→ 写策略时：连战前注意心情，避免连续比赛导致掉心情。

**体力**：保持在「一半左右浮动」即可；低体力会**降低训练成功率**，训练失败可能吃严重惩罚事件（**智力训练失败无惩罚**——这是为什么缺体力时可优先考虑智力训练/智力卡）。

## 4. 羁绊与友情训练（彩圈）——前期核心

- 训练时支援卡**随机出现在某些训练项**，在该项训练既能拿支援增益，也能攒该支援卡的**羁绊**。
- 羁绊满 **4 格** 且支援卡出现在**符合其类型**的训练项 → 触发**友情训练（彩圈）**，一次性高额收益。
- 策略：**前期哪里人多点哪里**（多人同框的强力借力），力争**第一次夏合宿前全员 4 格羁绊**；5 人齐聚某属性这种机会必点。
- 支援卡上出现**红色感叹号** → 该训练会触发**事件**（给技能 hint / 少量属性 + 更多羁绊）。
- **「爱娇」**buff（前期获得）会让羁绊涨得更快，是凹上限的关键。

> 与「训练等级」一样：URA 靠「每训练 4 次 +1 级」，青春杯/巅峰杯靠队伍评级/道具，通用层无法统一，需剧本层实现。

---

## 5. 训练等级与夏合宿

- **训练等级**越高，该属性训练收益越大，要**优先聚焦主训练项**快速升级。
- **夏合宿**（第二年、第三年 7 月上—8 月下，各 4 回合）：训练等级**固定 LV5**，是属性暴涨窗口，必须全力利用。
- 策略：进合宿前尽量**满体力 + 满心情 + 无 DB**，合宿期全部砸在主属性/友情训练上。

## 6. 技能系统（如何取舍）

- 技能点来自训练 + 比赛；学习技能消耗技能点。
- **Hint（技能提示）**降低学习消耗，且来自：马娘自带/觉醒、支援卡事件、比赛、继承因子。
- **「切者」buff** 大幅降低所有技能的学习消耗——凹上限的关键。
- 比赛中**技能触发**才是收益来源，分：增益（速度/加速/出闸/变道/视野/回耐）、减益（削耐/减速/焦躁延长/限视野）、被动（满足条件+固定属性）、**固有技能**（马娘自带大招）。
- 取舍策略：
  - 大赛（固定赛道/天气/季节）：**条件性绿技必定触发** → 绿技含金量极高，按「当天赛道」选技能。
  - 竞技场（JJC）：**堆上位技能数量** + 高智力（高发动率/多技能点）。
  - 长距离必点**金回耐**（耐力回复上位技能）。
- **固有技能升级条件**（URA）：情人节（6 万/泥地 4 万粉丝）、粉丝感谢节（7 万/泥地 6 万 + 理事长羁绊 3 格）、圣诞节（12 万/泥地 8 万）。

---

## 7. 比赛的取舍

- **生涯目标赛必跑**；额外跑 **G1/G2** 是主要「属性+技能点+hint」来源之一。
- 决策：当**训练收益一般、体力又容易溢出**时，用高等级比赛替代低价值训练（收益更多）。
- 等级：G1 > G2 > G3 > OP > 出道赛；越高级奖励越多。
- 场地：芝/泥、左右回、路况（良/稍重/重/不良——路况差削力、增耐耗）、天气。
- 大赛专属备赛：留意与大赛**同赛道同条件**的比赛去拿对应绿技 hint。

## 8. 剧本差异速览（总览各剧本的核心，供分层实现）

| 剧本 | 训练等级机制 | 核心玩法 | 对策略的影响 |
|------|--------------|----------|--------------|
| **URA** | 每训练 4 次 +1 级 | 生命周期固定；靠羁绊/友情训练 | 最基础；训练/事件收益为主，比赛按生涯跑 |
| **青春杯（あおはる）** | 按「队伍属性评级」提升 | 组队赛（每半年）、青春特训→青春槽→**魂爆**、青春系列技能、联动角色加成 | **训练收益抬升、比赛收益下降** → 少跑多训；魂爆可拿去补次要属性，魂爆自带适性 hint；智力卡/友人卡价值大增 |
| **巅峰杯**（原作 2022，日服） | 继承 URA，道具可协助 | **历战为核心**（一场育成 30+ 场）、商店道具（回体/训练增益/比赛增益/切者等）、自由赛程、劲敌、系列赛奖励事件、决赛 | **多打比赛**是核心；商店买回体/训练增益/比赛收益道具；卡强力但更耗时 |
| **凯旋杯/凯旋门**（本程序第 3 剧本，国服） | 待定 | 待完成（`KaisenConfig` A 档占位：普通模式 / 挑战训练员技能考试） | **尚未定稿**；骨架已就绪，需按实际机制补充远征/海外训练、凯旋门目标赛、シナリオリンク等 |

> **结论**：通用框架只覆盖「训练打分 + 体力/心情/羁绊 + 比赛取舍」这一层；
> 各剧本的**特殊规则**（魂爆次数、商店道具、自由赛程、队伍评级、固有升级条件）必须通过 `ScenarioConfig`（`UraConfig` / `AoharuConfig` / `KaisenConfig`）与各 `*_scenario.py` 独立实现，不能写死在通用 `ai.py` 里。

## 9. 落地到本程序的关键点

- `config.yaml` / 任务配置里：**培育目标属性 `expect_attribute`** 决定训练优先级，务必与**配卡类型比例**匹配。
- `ai.py::get_operation` 已实现「通用回合决策」，其中：
  - `get_training_basic_attribute_score` 负责「属性缺口边际价值」；
  - `get_training_support_card_score` + `get_support_card_event_score`（**仅 URA 生效**）；
  - `get_training_level_score` 按目标属性比例给训练等级分；
  - 阶段权重按 `date` 切换（36/40/48/60/64）。
- 建议后续优化方向（与本文档一致）：
  1. 把「特殊剧本规则」从通用函数中剥离，放到各自剧本配置/策略模块；
  2. 引入「连战心情惩罚」「合宿前满状态」等显式规则；
  3. 比赛取舍从「只在 extra_race/生涯赛跑」扩展为「训练收益低 + 体力溢出 → 跑 G1」。
