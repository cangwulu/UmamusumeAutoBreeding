# 赛马娘游戏机制完全攻略

> 来源：NGA 赛马娘板块综合攻略（训练/心情/羁绊/技能/比赛/因子继承/URA/青春杯/巅峰杯/活动）
> 落地时间：2026-09-02

---

## 一、游戏概述

赛马娘玩法主要分为：
- **PVE 剧本养成**（占据决定性主要部分）
- **PVP 竞技场与大赛**

每位马娘有"生涯"——固定要参加并获取一定名次的比赛，或在某时间前达成特定粉丝数量，未达成则育成结束。

## 二、属性系统

### 五维属性

| 属性 | 日文 | 作用 |
|---|---|---|
| 速度 | スピード | 所有马娘都很重要，越高越好（妨碍特化马娘除外） |
| 耐力 | スタミナ | 可理解为"HP"，赛程越长需求越高，不够会失速散步 |
| 力量 | パワー | 影响位置争夺、冲出马群、加速度；满足速耐基础上越高越好 |
| 根性 | 根性 | 影响位置争夺、最终冲刺、耐力不足时速度 |
| 智力 | 賢さ | 影响技能发动率，减少"掛かり"（焦躁），影响巡航/冲刺/位置意识 |

### 训练副属性

| 训练 | 大量提升 | 少量提升 | 其他 |
|---|---|---|---|
| 速度 | 速度 | 力量 | 少量技能点 |
| 耐力 | 耐力 | 根性 | 少量技能点 |
| 力量 | 力量 | 耐力 | 少量技能点 |
| 根性 | 根性 | 力量、速度 | 少量技能点 |
| 智力 | 智力 | 速度 | 较多技能点，回复少量体力 |

- 体力较少时训练成功率降低，训练失败有严重惩罚（仅智力训练失败无惩罚）
- "練習上手◯"提升训练成功率
- URA：每4次训练提升1级训练等级
- 第二三年7月上-8月下各4回合夏合宿，训练等级固定LV5

| 等级 | 训练效果 | 比赛属性 |
|---|---|---|
| 绝好调 | +20% | +4% |
| 好调 | +10% | +2% |

提升心情：外出（散步+1阶/祈福+1阶/唱K+2阶）、部分事件、比赛优胜
降低心情：负面事件、连续三次比赛、训练失败、部分固定事件

## 四、羁绊与友情训练

- 支援卡随机出现在训练项目，训练时享受增益并提升羁绊
- 羁绊达第四格 + 支援卡在对应类别训练 → 触发友情训练（彩圈），获得高额加成
- 红色感叹号 = 训练会触发事件（技能hint/少量属性/更多羁绊），多个叹号只随机触发一个
- "爱娇"buff 提升羁绊增加速度，游戏早期获得爱娇是凹上限的关键

## 五、技能系统

### 技能类型

**增益技能**：
- 速度技能：满足条件时提升速度
- 加速度技能：满足条件时提升加速度
- 出闸技能：减少起跑时间（集中力&集中力上位）
- 变道技能：满足条件时提升变道速度
- 视野技能：满足条件时提升视野
- 耐力回复技能：满足条件时回复耐力

**减益技能**：
- 耐力减少、速度减少、焦躁延长、视野限制

**被动技能**：
- 满足被动条件时提升对应属性（速度/力量/耐力/根性/智力，部分附带视野）

### 技能获取途径
- 马娘自带技能&觉醒技能
- 育成事件技能hint（降低学习所需技能点）
- 继承时技能因子触发
- 比赛获得技能hint
- "切れ者"buff 大幅降低所有技能学习所需技能点

## 六、比赛系统

### 比赛分类
- 等级：G1/G2/G3/OP/出道赛（等级越高奖励越多）
- 路况：良场/稍重场/重场/不良场（路况差→力量削减+耐力消耗提高）
- 天气：晴/阴/雨/雪
- 赛道：芝（草地）/ダート（泥地）
- 距离：短<1400 / 英里<1800 / 中距离<2400 / 长距离>2401

### 跑法
- 逃马：全程领跑保持优势到最后
- 先行马：开局抢第一梯队，维持逃马之后，最后冲刺
- 差马：第二梯队保存体力，最后突围冲刺
- 追马：不抢位置，全程保持体力，最后1穿N

## 七、角色卡强化

### 觉醒LV强化
- 消耗金币及育成素材（G1比赛锦旗、跑鞋等）
- 奖励：解锁新技能，其中2个为上位技能
- 优先提升至关键上位技能的LV3即可

### 才能开花
- 消耗马娘碎片（抽重复/母猪石兑换）
- 1→3十分重要（固有技能升级为标准强度+解锁因子遗传）
- 3→5无质变

## 八、因子继承系统

### 蓝色因子（属性因子）
- 对应5种属性，分1-3星
- 3星给21，2星给12，1星给5
- 继承对象及亲代的蓝色因子都生效，理想9蓝
- 五维达到600即有机会产出3星蓝因子
- 1、2星蓝因子在第二三次继承中有概率不继承

### 粉色因子（适性因子）
- 提供场地/距离/跑法适性改造
- 开局最多上升1-4阶段，需1/4/7/10个粉因子，最多升至A
- 两次3月后继承时有概率继续触发，每次上升1阶段
- A→S：距离适性提升速度，场地适性提升力量，跑法适性提升智力
- 纯随机产出，无已知提升途径

### 绿色因子（固有技能因子）
- 继承角色弱化版固有技能
- 育成初始根据父母绿色因子必定继承一次，1星-10%/2星-20%/3星-30%折扣
- 只有3星马娘可产出绿色因子
- 产出与评价分有关（但实际感受不到差距，近似随机）

### 白色因子（技能/赛场/剧本因子）
- 比赛因子：提供技能打折+属性
- 技能因子：只提供技能打折
- 剧本因子：提供属性（URA→速耐10-30，其他剧本不同）
- 第二三次继承时随机出现，提高出现概率的方法是提高种马相性
- 评价分超过SS时高星白色因子产出率大幅提升

### 继承时机
- 育成开始时：固定触发蓝色因子最大值 + 亲代绿色因子
- 第二年3月后：随机roll点继承
- 第三年3月后：随机roll点继承

## 九、相性系统

1. 种马和祖辈尽量避开樱花进王、乌拉拉和丸善斯基（相性极低）
2. 种马和父母打相同比赛可提升相性（仅G1/G2/G3，不含OP/Pre-OP/出道/URA；不同年份同名比赛不重复）
3. 特殊联动比赛给予金色奖章额外增加相性（经典三冠/春三冠/秋三冠等，均为G1）
4. 养种马尽量多打G1比赛，打有特殊联动的比赛获金奖章
5. 借好友种马当祖辈是最佳选择

## 十、URA 剧本

### 训练等级提升
URA：多次训练，每4次提升1级

### 固有技能升级（3次机会）
| 时机 | 粉丝需求 | 其他条件 |
|---|---|---|
| 第三年2月后（情人节） | 6万（泥地4万） | - |
| 第三年4月前（粉丝感谢节） | 7万（泥地6万） | 理事长羁绊3格 |
| 第三年12月前（圣诞节） | 12万（泥地8万） | - |

### 育成流程
**序盘（开局-第一次继承前）**：
- 哪里人多点哪里（羁绊优先）
- 友人卡3格羁绊触发外出解锁
- 关注关键技能hint红点
- 聚焦主训练项提升等级
- 12月前有两个G1英里赛，12月后有G1中距离赛

**中盘（第一次继承-第二次夏合宿后）**：
- 友情训练优先，不错过多彩圈
- 6月左右休息，满体力+满心情进合宿
- 菊花赏推荐400耐+回耐技能，天皇赏春至少600耐+回耐
- 理事长羁绊要在4月前达3格
- 11月前达5万粉丝额外获技能点+智力

**终盘（第二次夏合宿-URA完赛）**：
- 多友情训练
- 跑日本杯/伊丽莎白女王杯/有马纪念等
- 记者和理事长羁绊影响完赛后追加奖励

## 十一、青春杯剧本

### 新增机制
- **组队赛**：半年1次，排名影响全队基础能力（1-5名+50全属性）
- **青春特训**：共同训练的队员有箭头标注，提升其能力+青春槽
- **青春爆魂**：4次青春特训后槽满，触发爆魂→大量属性+技能hint
- **训练等级**：根据队伍属性评级提升（非训练次数）
- **青春杯特殊技能**：第三年11月后半，根据魂爆次数提供
  - 0-3次：无 / 4-6次：点火HINT1 / 7-9次：点火HINT3 / 10-12次：燃烧HINT1 / 13+次：燃烧HINT3
- **联动角色**：米浴/乌拉拉/福来/大树快车（魂爆提供更多属性+队伍名对应金技能）

### 队伍名→金技能
| 队伍名 | 金技能 |
|---|---|
| キャロッツ（默认） | ノンストップガール |
| ハレノヒ・ランナーズ（福来） | 千里眼 |
| HOP CHEERS（大树快车） | マイルの支配者 |
| ブルームス（米浴） | クールダウン |
| にんじんぷりん（乌拉拉） | 不屈の心 |

### 育成要点
- 青春特训优先（槽未满时价值大于羁绊未满的普通训练）
- 智力卡/友人卡价值提升（体力消耗增加）
- 比赛收益相对降低，不推荐跑很多比赛
- "切れ者"buff十分关键

### 道具购买思路
- **回体道具**：多多益善，绿汁心情惩罚影响不大
- **训练增益**：喇叭优先60%2回合和40%3回合，负重选主训练属性，御守多多益善
- **比赛增益**：保证35%覆盖巅峰杯决赛三场
- **心情回复**：手头1-2个足矣
- **属性提升**：10币+3不考虑，15币+7和30币+15有就考虑
- **BBQ**：≥2个支援卡羁绊不满就考虑
- **切れ者**：关键但看技能点是否够用

### 育成流程
**序盘**：羁绊优先 + 理事长羁绊 + 主训练等级 + 劲敌比赛 + 早期BBQ
**中盘**：按规划跑赛事触发奖励事件 + 合宿前全员4格羁绊 + 道具准备
**终盘**：友情训练 + 继续赛事规划 + 合宿道具 + 巅峰杯Finals前3个35%蹄铁

### 历战惩罚
- 3连战以上&体力为0时跑比赛→心情下降/DB/削减属性
- 体力有1点就不会触发，小体力上限药可做润滑剂
- 每年最后一回合（有马回合）跑比赛不触发历战惩罚

## 十三、支援卡编成

### 编成类型
| 类型 | 构成 | 目标 |

| 速力 | 2-3速卡+2力卡+友人 | 高速度+高力量 |

- 长距离：速耐

## 十四、活动系统

### 剧情活动
- 1-2月一次，同期开放换皮卡池
- 免费SSR支援卡（面板一般但提供上位技能）
- 活动点数报酬 + BINGO转盘

### 传奇杯
- 在现实比赛中挑战有史实根据的马娘
- 每天3次免费参加
- 首胜：马娘碎片+萝卜+金币；之后：碎片+金币+支援卡经验

### G1赛事活动
- 每逢现实G1比赛开放限定任务
- 奖励：金币、萝卜、支援卡经验

### SHOWTIME活动
- 5个难度级别，通关解锁
- LV5：对手超强+固定绝好调+不能用闹钟
