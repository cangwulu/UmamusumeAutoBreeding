python tools/update_assets.py --dry-run 国服更新后一键刷新数据（--dry-run 先预览步骤；全量 / --chars-only / --cards-only）
python tools/regress_name_resolver.py 名称解析回归；其余回归测试见 tests/（事件 / 技能 / 相性 / 规划）
python module/umamusume/asset/stud_planner.py --race 中山大奖赛 --top 3 只列出 Top 候选与缺口（快速版）；比赛名可用简中权威名（如 有马纪念 → 中山大奖赛）
